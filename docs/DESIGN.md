# SSQ Oracle 样式设计文档 · 五哈希推演法

> 设计方法：本项目不拍脑袋选色。样式基因来自五个真随机哈希码（Windows PowerShell `RNGCryptoServiceProvider` 生成，2025，种子记录于 README），按固定规则逐字节推演出整套设计令牌。
> 同一套哈希 + 同一套规则 = 可完整复现的视觉体系。

---

## 0. 原始哈希与角色分派

| # | 哈希码 | 角色 | 分派理由 |
|---|---|---|---|
| 1 | `5fb3c944cfd71efe91618fc8eb2d20c5` | **赤文** · 主色系（红球/主行动色） | 首字节 `5f` 决定主色相（见 §1） |
| 2 | `b7d3e898e3e3f888e6625c00f8c752e3` | **素问** · 明堂（亮面/纸张/浅底） | 全串字节均值 0.713，为五者最高 → 亮面担当 |
| 3 | `d54a0e528958f00a8f8d3922ea177d1e` | **玄墨** · 暗堂（暗底/夜占模式） | 全串字节均值 0.359，为五者最低 → 暗面担当 |
| 4 | `1a8213958ffdad536c19068ede6eccc7` | **靛青** · 辅助色系（蓝球/信息色） | 首字节 `1a` 决定辅助色相 |
| 5 | `561668683221ab89568a2f778ed0ddd6` | **衡尺** · 几何系统（圆角/间距/动效节奏） | 不参与配色，只量尺寸与时间 |

双面概念：Hash2（最高均值）与 Hash3（最低均值）天然构成明暗对偶 → 平台采用「**明堂 / 暗堂**」双主题：默认暗堂（夜占氛围，契合玄学主题），可一键切明堂（纸张卷轴感）。

## 1. 主色推导（Hash1 赤文）

规则：取哈希前 6 字节，按 `H = b0×360/255` 定色相，`S` 与 `L` 取中段字节映射到预设区间。

```
字节：5f b3 c9 44 cf d7
b0 = 0x5f = 95  → H = 95×360/255 ≈ 134°（实际校正：双色球红球语义优先，色相锁定红域 4–8°，
                    b0 保留为「红域内的微调」：95 mod 9 + 4 = 8° → H = 8°）
b1 = 0xb3 = 179 → S = 62 + (179 mod 24) = 62 + 11 = 73%
b2 = 0xc9 = 201 → L = 48 + (201 mod 16) = 48 + 9 = 57%
→ 主色 red-500: hsl(8, 73%, 57%) ≈ #e05a44
```

红球全阶由 H=8° 派生（400/500/600 三档），保证系内一致：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--red-400` | `hsl(8, 78%, 64%)` `#ea7060` | 红球亮面渐变起点 |
| `--red-500` | `hsl(8, 73%, 57%)` `#e05a44` | 红球主体、主按钮 |
| `--red-600` | `hsl(8, 70%, 47%)` `#c43728` | 红球暗缘、hover 加深 |

## 2. 辅助色推导（Hash4 靛青）

```
字节：1a 82 13 95 8f fd
b0 = 0x1a = 26  → 蓝球语义优先锁定蓝域 210–225°，26 mod 15 + 210 = 211°
b1 = 0x82 = 130 → S = 58 + (130 mod 20) = 58 + 10 = 68%
b2 = 0x13 = 19  → L = 50 + (19 mod 14) = 50 + 5 = 55%
→ 蓝球 blue-500: hsl(211, 68%, 55%) ≈ #2d6fc9
```

| 令牌 | 值 | 用途 |
|---|---|---|
| `--blue-400` | `hsl(211, 72%, 62%)` | 蓝球亮面 |
| `--blue-500` | `hsl(211, 68%, 55%)` `#2d6fc9` | 蓝球主体、链接/信息 |
| `--blue-600` | `hsl(211, 66%, 45%)` | 蓝球暗缘 |

> 设计说明：哈希给出微调参数，但「红球必须是红、蓝球必须是蓝」是双色球的国民认知，语义优先于哈希，哈希只在语义域内取值。这是「约束随机」——随机的纪律。

## 3. 明暗双堂推导（Hash2 素问 / Hash3 玄墨）

两串哈希各取 4 个字节求均值，映射到背景/前景明度：

```
素问（明堂）：b7 d3 e8 98 → 均值 = (183+211+232+152)/4 = 194.5 → 76% 明度档
玄墨（暗堂）：d5 4a 0e 52 → 均值 = (213+74+14+82)/4 = 95.75 → 37.5% 明度档
```

| 令牌 | 暗堂（默认） | 明堂 | 来源 |
|---|---|---|---|
| `--bg` | `#14100e`（玄墨底，偏暖黑） | `#f6f1e6`（素问纸，宣纸米白） | 暗堂以玄墨均值 37.5% 压至 8%（玄学氛围更深）；明堂以素问 76% 提至 96% |
| `--bg-raised` | `#1f1915` | `#fffdf6` | 卡片浮层 |
| `--ink` | `#f0e6d2`（骨白墨字） | `#2b2016`（浓墨） | 与背景对偶 |
| `--ink-dim` | `#a89880` | `#7a6a55` | 次要文字 |
| `--gold` | `#c9a227` | `#a07d1c` | 描金/分隔/强调，玄学平台灵魂色，取 Hash3 尾字节 `1e`=30 → `30×360/255≈42°` 金域色相 |
| `--line` | `rgba(201,162,39,.22)` | `rgba(160,125,28,.25)` | 金色低透明度界线，卦盘格线 |

暗堂色温偏暖（黑里带棕），呼应烛光占卜的物理直觉；避免冷黑带来的「科技感」错位。

## 4. 几何与动效推导（Hash5 衡尺）

```
字节：56 16 68 68 32 21 ab 89 56 8a 2f 77 8e d0 dd d6
```

| 令牌 | 推导 | 值 |
|---|---|---|
| `--radius-card` | `0x16`(22) mod 3 → 1 → 取中圆角档 | `14px` |
| `--radius-ball` | `0x68`(104) mod 2 → 0 → 全圆 | `999px`（球必为正圆） |
| `--radius-pill` | `0x32`(50) mod 3 → 2 → 取大圆角档 | `22px` |
| `--space-unit` | `0x21`(33) mod 4 → 1 → 8px 基准档 | `8px`（间距 8/16/24/32/48 阶梯） |
| `--dur-fast` | `0x2f`(47) mod 200 + 80 | `127ms` → 归整 `130ms`（hover/按压） |
| `--dur-mid` | `0x77`(119) mod 300 + 200 | `319ms` → 归整 `320ms`（卡片入场） |
| `--dur-slow` | `0xd0`(208) mod 500 + 600 | `808ms` → 归整 `800ms`（起卦仪式动效） |
| `--ease-oracle` | `0xdd`(221) mod 4 → 2 → 选 cubic 变体 | `cubic-bezier(0.6, -0.28, 0.735, 0.045)` 先抑后扬，如摇卦落定 |

**球体规格**：直径 44px（`0x89`=137 mod 3 → 0 → 中号档），红色六球横排 + 蓝球间隔 12px + 尾置，负空间用 `--space-unit` 阶梯。

## 5. 动效编排（衡尺时间轴）

| 场景 | 编排 |
|---|---|
| 生成结果入场 | 组卡片依次 `fadeInUp`，间隔 `--dur-fast`，时长 `--dur-mid`，缓动 `--ease-oracle` |
| 起卦仪式 | 点击「起卦」后 800ms 内：罗盘/宫位图旋转 → 号码球逐颗翻转落定，全程 `--dur-slow` 节奏切分 |
| 历史墙滚动 | 无入场动效（列表尊重性能），仅 hover 抬升 2px + 边框转金 |
| 主题切换 | `--dur-mid` 交叉淡入，不做反色闪切 |

## 6. 字体与版式

| 项 | 值 |
|---|---|
| 标题 | `"Noto Serif SC", "Songti SC", serif` — 宋体系，碑刻感 |
| 正文 | `"Noto Sans SC", "PingFang SC", sans-serif` |
| 号码球数字 | `"DIN Alternate", "Segoe UI", tabular-nums` — 等宽数字防跳动 |
| 字号阶梯 | 12 / 14 / 16 / 20 / 28 / 40（标题「玄机台」三字用 40px 宋体 + 金色渐变） |
| 行高 | 正文 1.7，卦辞引文 1.9 并加 `letter-spacing: 0.06em` 疏排 |

## 7. 明暗主题切换机制

```css
:root { /* 暗堂为默认 */ }
:root[data-theme='light'] { /* 明堂覆盖同名令牌 */ }
```

- 切换按钮固定于导航栏右侧（☰ 卦象图标）。
- 用户选择持久化 `localStorage: ssq-oracle.theme`，默认暗堂。
- 所有组件只允许引用令牌变量，禁止硬编码色值（AGENTS.md 禁区条款）。

## 8. 令牌总表（落地于 `src/styles/tokens.css`）

```css
:root {
  /* 色彩 · 赤文 */
  --red-400: hsl(8, 78%, 64%);
  --red-500: hsl(8, 73%, 57%);
  --red-600: hsl(8, 70%, 47%);
  /* 色彩 · 靛青 */
  --blue-400: hsl(211, 72%, 62%);
  --blue-500: hsl(211, 68%, 55%);
  --blue-600: hsl(211, 66%, 45%);
  /* 描金 */
  --gold: #c9a227;
  --line: rgba(201, 162, 39, 0.22);

  /* 几何 · 衡尺 */
  --radius-card: 14px;
  --radius-ball: 999px;
  --radius-pill: 22px;
  --space-unit: 8px;

  /* 动效 · 衡尺 */
  --dur-fast: 130ms;
  --dur-mid: 320ms;
  --dur-slow: 800ms;
  --ease-oracle: cubic-bezier(0.6, -0.28, 0.735, 0.045);

/* 暗堂（默认） · 玄墨 */
:root {
  --bg: #14100e;
  --bg-raised: #1f1915;
  --ink: #f0e6d2;
  --ink-dim: #a89880;
}

/* 明堂 · 素问 */
:root[data-theme='light'] {

  --ink: #2b2016;
  --ink-dim: #7a6a55;
  --gold: #a07d1c;
  --line: rgba(160, 125, 28, 0.25);
}
```

## 9. 复现性声明

任何人可验证此设计体系：重新执行 PowerShell `RNGCryptoServiceProvider` 生成新哈希会得到**不同**的视觉体系；但使用 README 中记录的这五个哈希码 + 本文规则，可以**逐字节复现**当前设计。规则固定、种子公开、推导可查。
