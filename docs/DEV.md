# SSQ Oracle 开发文档

> 双色球娱乐预测平台 · 纯前端实现
> 版本 v1.0 · 状态：设计定稿，待脚手架落地

---

## 0. 项目边界声明

- **性质**：娱乐工具。所有「预测」均为确定性可复现的随机化与统计展示，不具备真实预测能力。
- **合规**：页面所有生成结果处必须附带「仅供娱乐」提示，不涉及任何销售、代购、合买功能。
- **数据**：无后端、无账号体系。开奖数据内置 JSON（示例数据 + 真实数据替换位），用户偏好（锁定/排除号、默认组数）存 `localStorage`。

## 1. 产品需求

### 1.1 往期号码查询（历史墙）

| 项 | 规则 |
|---|---|
| 展示范围 | 最近 45 期，可翻页/滚动加载 |
| 单期展示 | 期号、开奖日期、6 颗红球（升序）、1 颗蓝球、销售额（可选展示） |
| 红蓝球样式 | 红球 `red` 令牌圆牌、蓝球 `blue` 令牌圆牌，与生成页同一 Ball 组件 |
| 筛选 | 期号关键字搜索；红球号码点选高亮（统计该号码在窗口期内出现次数） |
| 数据结构 | `SSQDraw[]`（见 §3.1），按期号降序排列 |

### 1.2 号码生成（1–5 组）

| 项 | 规则 |
|---|---|
| 组数 | 1–5 组，`GroupCountStepper` 步进器选择 |
| 每组 | 6 个不重复红球（01–33）+ 1 个蓝球（01–16），红球升序展示 |
| 幸运号自定义 | 锁定 0–6 红球 + 锁定 0–1 蓝球；排除 0–27 红球 + 排除 0–15 蓝球 |
| 约束校验 | 锁定与排除号码的交集必须为空；锁定红球 ≤ 6，锁定蓝球 ≤ 1，锁定红+排除红 ≤ 32（保证可行解空间非空）；蓝球若全部被排除则锁定蓝球必填 |
| 生成时机 | 手动点击生成；每次点击所有组重摇（锁定号除外） |
| 结果展示 | 每组带独立卡片，可一键复制该组号码；页脚统一附「仅供娱乐」声明 |

### 1.3 预测算法

#### A. 常规数学期望预测（`math`）

纯统计学，从最近 N 期（默认 30，范围 10–45）历史中计算：

| 步骤 | 算法 |
|---|---|
| 1. 频次统计 | 每个红球号码出现次数 / 蓝球号码出现次数 |
| 2. 热温冷分层 | 按 Z 分数划分：`z ≥ +0.75` 热、`-0.75 < z < 0.75` 温、`z ≤ -0.75` 冷 |
| 3. 遗漏值 | 每个号码距上次开出的期数 |
| 4. 混合打分 | `score = 0.5×频次归一 + 0.3×热度权重 + 0.2×遗漏回补权重`（遗漏超过均值 1.5 倍视为「该回了」加分） |
| 5. 抽取 | 红：分层抽样保证热/温/冷都有代表（热 3 ± 1、温 2 ± 1、冷 1 ± 1）；蓝：Top 频次中随机取一 |
| 6. 幸运号 | 锁定号直接占位后从剩余池抽取；排除号剔除出池 |

分层配比带随机扰动，避免每次生成结构雷同。

#### B. 卦象推演预测（`oracle`）

**参考典籍**：《易经》（卦象与卦辞）、《增补秘传万法归全》小六壬体系、五行生克（《五行大义》）、天干地支历法。以下规则为**工程化转译**，非严格术数考据，文档明示转译口径。

**B0. 起局（占卜方法与实践技巧的转译）**

1. **时间起局**：以用户点击时刻的干支纪时为「问事之时」（见 B3 干支引擎）。
2. **心念起数**：提示用户「心中默想所问之事」，记录点击时的毫秒时间戳，`毫秒 mod 6` 类比「数由心起」的触机；用于小六壬掐指定位。
3. **诚心校验**（趣味化）：若用户 10 秒内连续 5 次点击生成，提示「心浮则卦乱，稍安勿躁」，强制 3 秒冷却——对应占卜实践中「一事一占、不重复占问」的忌讳。

**B1. 小六壬（六宫掐指）**

- 六宫序列：**大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡**。
- 起法：月、日、时（辰）三数依次在六宫上顺数，最终落宫定吉凶基调。
- 工程转译：落宫决定本组红球抽取的「池温偏移」——大安/速喜/小吉 → 向热号池偏移；留连/赤口 → 均衡池；空亡 → 向冷号池偏移（「空亡主虚」，反而寻冷门）。
- 宫位颜色与语义展示在结果卡片上（大安青木、速喜朱火、小吉水黑、空亡土黄等，配色取自五行）。

**B2. 易经起卦（梅花易数心法转译）**

1. **起上卦**：`(年支序数 + 月数 + 日数) mod 8`，对应先天八卦序（乾一兑二离三震四巽五坎六艮七坤八），余 0 作 8。
2. **起下卦**：`(月数 + 日数 + 时支序数) mod 8`，同上。
3. **动爻**：`(年 + 月 + 日 + 时) mod 6 + 1`。
4. **本卦与变卦**：动爻阴阳反转变出变卦；从内置 64 卦数据中取出本卦卦名、卦辞。
5. **卦辞映射**：内置 64 卦每卦标注 `temper`（ temperament ∈ 进取 / 守成 / 变通 / 静守）——工程转译为红球热温冷池的采样配比系数。

**B3. 天干地支与五行生克**

- **干支引擎**：JS 实现公历 → 干支换算（年干支、日干支、时干支），核心为基准历元偏移取模：
  - 年干支：`(年份 - 4) mod 10` 定天干、`(年份 - 4) mod 12` 定地支（立春分界此处从简按公历年处理，文档注明简化）。
  - 日干支：以已知基准日（如 2000-01-01 为戊午日类基准）偏移天数 `mod 60`。
  - 时干支：日干定 `五鼠遁` 起时干，时支按 23–01 起子时。
- **五行归属**：天干（甲乙木、丙丁火、戊己土、庚辛金、壬癸水）、地支（寅卯木、巳午火、申酉金、亥子水、辰戌丑未土）。
- **生克转译**：
  - 计算当日的「日主」五行 → 号码池编号 `1–33` 按 `n mod 5` 映射五行（1、6 水，2、7 火，3、8 木，4、9 金，5、10 土，循环至 33，河图数理转译）。
  - **生我者**（生日主之行）对应的号码池加权 ×1.5；**我生者** ×1.2；**克我者** ×0.7；**我克者** ×0.9；**同我者** ×1.3。
  - 蓝球 1–16 同法映射。

**B4. 卦象算法合成管线**

```
点击生成
  ├─ 干支引擎：算出当日当日干支、时辰 → 五行权重表
  ├─ 小六壬：月日时掐指 → 落宫 → 池温偏移
  ├─ 梅花易数：年月日时起卦 → 本卦卦辞 → 采样配比
  ├─ 五行生克：号码池加权
  ├─ 幸运号：锁定占位 / 排除剔除
  └─ 加权随机抽样 → 升序去重 → 输出 + 展示卦名卦辞、宫位、五行标注
```

每次生成同步产出一份「推演盘面」：本卦卦名与卦辞摘录、小六壬落宫、当日干支、五行旺衰——让结果「讲得出一套话」，这是娱乐体验的核心。

#### C. 算法统一接口

```ts
type AlgoKind = 'math' | 'oracle';

interface AlgoContext {
  history: SSQDraw[];          // 最近 45 期
  locks: NumberLocks;          // 锁定号
  excludes: NumberLocks;       // 排除号
  now: Date;                   // 起局时刻
}

interface AlgoResult {
  groups: SSQPick[];           // 1–5 组
  reading: OracleReading | null; // oracle 算法才有推演盘面
}
```

两个算法都实现 `(ctx: AlgoContext, groupCount: number) => AlgoResult`，由 `usePrediction` hook 调度。

### 2.3 关键设计决策

| 决策 | 理由 |
|---|---|
| 开奖数据内置 JSON 而非接口抓取 | 无后端边界；官方数据接口不稳定且需 CORS/密钥，预留 `data/draws.json` 替换位即可，更新期手动替换 |
| 算法同步计算不进 Web Worker | 45 期数据量 + 5 组生成的计算量在毫秒级，Worker 反而增加复杂度 |
| 64 卦数据内置 JSON 而非完整卦辞库 | 卦辞展示取每卦一句核心断语，控制体积 |
| 纯 CSS 令牌不用 Tailwind | 五哈希推导的自定义令牌体系是本项目特色，Tailwind 会稀释它 |

## 3. 核心数据类型

```ts
/** 一期开奖 */
interface SSQDraw {
  issue: string;        // 期号，如 "2025041"
  date: string;         // 开奖日 "2025-04-13"
  reds: number[];       // 6 个升序红球 1–33
  blue: number;         // 蓝球 1–16
}

/** 一组生成结果 */
interface SSQPick {
  reds: number[];       // 6 个升序红球
  blue: number;
}

/** 幸运号约束 */
interface NumberLocks {
  redLocks: number[];      // ≤6
  blueLock: number | null; // ≤1
  redExcludes: number[];
  blueExcludes: number[];
}

/** 卦象推演盘面 */
interface OracleReading {
  ganzhi: { year: string; day: string; hour: string };  // 干支标注
  liurenPalace: string;        // 小六壬落宫名
  liurenMeaning: string;       // 宫位断语
  guaName: string;             // 本卦卦名，如 "水火既济"
  guaText: string;             // 卦辞摘录
  guaTemper: '进取' | '守成' | '变通' | '静守';
  wuxingWeights: { element: string; weight: number }[]; // 五行旺衰
}
```

## 5. 风险与备注

- **数据时效**：内置 45 期为**真实开奖数据**（来源：福彩官网 www.cwl.gov.cn 开奖公告接口，抓取于 2026-11-10，截至 2026129 期）；数据以静态 JSON 内置，应用离线运行，开奖更新后手动替换 `data/draws.json` 内容；`history.ts` 预留 `loadDraws()` 单一入口，未来可无痛切换远程数据源。
- **干支简化**：年干支按公历年取整（未按立春精确分界），对娱乐场景足够；如需精确可后续接入 lunar-javascript。
- **随机数**：使用 `crypto.getRandomValues` 封装 `random.ts`，保证浏览器端质量。
- **免责**：About 页 + 生成页脚注双重声明，文案固定不得删除。
